# Nexus AI — The Future of Artificial Intelligence

A complete, production-ready single-page website for a fictional AI technology company.  
Built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript** — no frameworks, no dependencies.

---

## 🚀 Live Demo

Deploy directly to GitHub Pages — works out of the box with no build step.

## 📁 Project Structure


## ✨ Features

### Design
- Dark futuristic theme with `#050816` base
- Glassmorphism cards and panels
- Neon cyan (`#00E5FF`) and violet (`#7C4DFF`) accent system
- Google Fonts: **Orbitron** (headings) + **Poppins** (body)
- Gradient borders, hover glow, animated transitions

### Sections
1. **Hero** — Animated starfield canvas, typing effect, floating SVG AI head with orbit rings
2. **About** — Neural network SVG illustration, animated reveal
3. **AI Solutions** — 6-card grid with hover lift, gradient top borders
4. **Robotics** — SVG robot illustration, spec table, 3-column feature cards
5. **Projects** — 4 project cards with custom SVG visuals
6. **Statistics** — Animated count-up counters triggered on scroll
7. **Timeline** — Interactive 4-milestone technology roadmap (2025–2035)
8. **Testimonials** — Auto-sliding carousel with swipe support
9. **CTA** — Animated gradient banner
10. **Contact** — Validated form with success notification + info card
11. **Footer** — 4-column layout with social links

### JavaScript
- ✅ Canvas starfield with shooting stars
- ✅ Typewriter cycling animation
- ✅ Scroll-triggered reveal animations
- ✅ Animated count-up statistics
- ✅ Testimonial carousel (auto-play, touch swipe, dot navigation)
- ✅ Sticky navbar with scroll shrink + active link tracking
- ✅ Mobile hamburger menu
- ✅ Contact form validation with success notification
- ✅ Page loader animation
- ✅ Back-to-top button
- ✅ Subtle card tilt on hover (desktop only)
- ✅ Demo modal

### Accessibility
- Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<footer>`)
- ARIA labels, `aria-live`, `aria-expanded`, `role` attributes
- Keyboard navigation with visible focus states
- `aria-hidden` on decorative SVGs
- `alt` equivalents via `aria-label` on meaningful graphics
- `prefers-reduced-motion` media query supported

### Performance
- Zero external JavaScript dependencies
- Google Fonts loaded with `preconnect`
- Passive scroll event listeners
- Debounced resize handlers
- `IntersectionObserver` for scroll effects (no scroll jank)

## 🛠 GitHub Pages Deployment

1. Push the entire folder to a GitHub repository
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://yourusername.github.io/nexus-ai/`
